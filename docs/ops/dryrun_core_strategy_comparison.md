## 表のポイントと重要インサイト

### 実質的なアルファ源泉（WOBI3 / WOBITAIL / TF2BP Baseline）

最も高いEVと勝率を叩き出しているのは、「大口壁の消化（OFI）を確認して順張りで入り、利確を固定幅で切らずにトレイリング/ラチェットで伸ばす戦略」です（WOBI3: EV +1.35 bp / 勝率 78%）。

TF2BP Baseline もスプレッド関門（≤1.2bp）を敷いた能動スキャルにより、累計 +1,000 bp 超と一貫した正の期待値を示しています。

### DRYRUN（紙）特有の約定ゲイン

WOBIMM や UMM が DRYRUN で見せる大きな黒字（+150〜+1,000 bp）は、「注文キュー待ちを無視した即時約定（Fictive Fill / 板クロス）」に支えられている側面が強く、キューシミュレーションを入れた HONEST モデルでは大幅に目減り（またはマイナス転落）することが確認されています。

### 早期損切り（AgingGuard）の逆効果

TF2BP_PEG_v3 のように「ノイズを恐れて3秒等の固定時間で成行脱出する」設計は、スプレッド摩擦（1〜2 bp）を連打されて勝率が 10% 前後まで崩壊し、検証打ち切り（TERMINATED）となっています。
