## 最近の戦略群から見出された「最新の重要インサイト」

### 「MS1 vs MS2」が暴いたスキャルの真実

入口条件が同じでも、EV_GONE 時に「Ask最良で Maker 売りを待つ（MS1: +76bp）」か「Bidへ投げて成行相殺する（MS2: −106bp）」かだけで **182bp のギャップ** が生じ、勝率が **61% ➔ 31%** へ崩壊することが実証されました。

### 「TF1A/TF2A」における早期カットの逆効果

+5bp ロックや +8bp トレイリングによる勝ち筋（勝率ほぼ100%）は完璧に機能している一方、初期ノイズを怖がって切る LEAD_ADVERSE_CUT（TF2A: 9本全敗 −28bp）は、過去の AgingGuard と同様に「勝ち芽を早摘みして MFE を窒息させる」ことが数字で確認されました。

### VR1（真空）の時間スケール

大口成行が突き抜けた直後は 1.5〜3.0秒ほどの板再補充（Refill）猶予が必要であり、1.0秒固定のタイムアウトは「最悪の底値で成行を投げる自爆」になることが判明しています。
